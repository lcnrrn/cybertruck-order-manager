# 구매자 주문·조회 백엔드 (Apps Script) 배포

주문 페이지(`order.html`)와 조회 페이지(`lookup.html`)는 시트 열쇠를 갖고 있지 않아요.
이 Apps Script 웹 앱이 사장님 구글 계정 권한으로 대신 시트에 쓰고 읽습니다.

## 5단계 (사장님이 직접, 약 3분)
1. 주문 시트를 열고 메뉴 **확장 프로그램 → Apps Script**
2. 기본 `Code.gs` 내용을 전부 지우고 이 폴더의 `Code.gs`를 통째로 붙여넣기 → 💾 저장
3. 오른쪽 위 **배포 → 새 배포** → 톱니 ⚙ → **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
4. **배포** → 권한 검토 → 계정 선택 → (경고 화면이면) 고급 → 안전하지 않은 페이지로 이동 → 허용
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 봇에게 보내기
   → 봇이 `src/buyer/config.ts`의 `APPS_SCRIPT_URL`에 넣고 다시 배포

## 하는 일
- `doPost`: 주문을 Orders 탭 **맨 아래 행에 추가만** (기존 행·S1·설정 탭은 건드리지 않음). 상태 대기, 주문경로 TKC,
  R 열은 `{i, v:2, x:{}}`. 제품명·가격은 설정 탭 products 에 있는 것만 받음. 닉네임·입금자명·요청사항은 `요청:` 메모로.
- `doGet?action=lookup&name=&last4=`: 이름 + 전화 뒷 4자리가 둘 다 맞는 주문만, 품목·입금/제작 상태·송장번호만 돌려줌
  (주소·전화번호·다른 사람 주문은 안 돌려줌, 지운 주문·예시 주문 제외, 같은 이름 1분 10회 제한).

## 코드를 고친 뒤
배포 → 배포 관리 → ✏ → 버전: **새 버전** → 배포 (URL 그대로 유지)
